- Это папка отвечает за модели менюшек.

Модели это обязательные менюшки без которых плагин не может работать.

ВЫ СПОКОЙНО МОЖЕТЕ ДУБЛИРОВАТЬ ЕСЛИ:

- Если вы хотите создать несколько гуи с разной конфигурацией но с той же моделью, тогда создайте модель в папке custom,
  потому что из папки models берётся только одна модель.

Вы можете настроить эти модели как хотите, главное чтобы каждая модель существовала, даже если не используется нигде.
