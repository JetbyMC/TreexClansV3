Это папка с кастомными менюшками, вы можете спокойно удалить этот файл (README.md) если хотите.

Чтобы открыть кастомные гуи, у вас есть два способа:
1. `open_args`: Вы указываете список подкомманд через которые игрок будет открывать. Например: `/clan example`, подкомманд может быть сколько угодно.
2. `[open]`: Важно, если вы хотите открыть ИМЕННО модель ИЗ ПАПКИ models, тогда используйте `[open] model:example]`, а если вам надо просто открыть кастомную гуи тогда `[open] example]`

Если вам нужно создать меню, где НУЖЕН КЛАН тогда используйте: `model: clan_only`, тогда игрок без клана не сможет открыть гуи, чтобы предотвратить проблем.
